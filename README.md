# Shah — Digital Marketing Portfolio

Source for the live portfolio at [temporary-spry-aurora-5xef5ih.vercel.app](https://temporary-spry-aurora-5xef5ih.vercel.app).

This is a static site. Open `index.html` locally or serve this directory with a static web server. Its pages include featured projects, four campaign case studies, an about page, and contact information. The VISAS Vision Global case study includes the original campaign reel.

The site is deployed through the existing Vercel project `temporary-spry-aurora-5xef5ih`. Local `.env*` files and `.vercel/` project metadata are excluded from Git.
